# 📝 Todo App

A modern and responsive Todo application built with **HTML**, **CSS**, and **Vanilla JavaScript**. This project demonstrates dynamic DOM manipulation, event-driven programming, input validation, and task management without using any external frameworks.

---

## ✨ Features

- ➕ Add new tasks
- 🗑️ Delete tasks
- ⚠️ Input validation with animated warning messages
- 🎨 Modern and responsive user interface
- ⚡ Dynamic DOM manipulation
- 📱 Responsive design for desktop and mobile devices

---

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript

---

## 📚 Concepts Practiced

- DOM Manipulation
- Event Listeners
- Event Delegation
- Dynamic Element Creation
- Input Validation
- CSS Animations
- Responsive Design
